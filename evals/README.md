# Evaluations

Datasets live in `evals/datasets/<id>/` with a `manifest.json` that records sources, gold
labels and a SHA-256 of every file. Run outputs go to `evals/reports/<run-id>/`
(`manifest.json`, `per_query.jsonl`, `metrics.json`, `failures.md`).

Rules:

- Gold labels are written by a human, never generated by the model under test.
- Unknown manifest values stay `null`. Never fill them with placeholder hashes or versions.
- Deterministic suites run in CI without a model. Real-model runs are opt-in and local.
